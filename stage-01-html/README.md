# Этап 1 — HTML

Откройте `index.html` в браузере (двойной клик или Live Server). CSS нет специально.

- Главная: `index.html`
- Вход без JS: `login.html`
- Карточка товара без JS: `product.html`
- Картинки из `Coral.fig` лежат в `images/`

Модалки внизу главной с атрибутом `hidden`. Чтобы посмотреть разметку, временно удалите `hidden`.
