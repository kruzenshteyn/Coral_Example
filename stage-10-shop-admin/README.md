# Этап 10 — корзина, заказы, админка

Запуск как на этапе 9, из этой папки:

```
cd php && php -S localhost:8000 router.php
cd django && python manage.py migrate && python manage.py seed && python manage.py runserver 8001
cd nodejs && npm install && npm start
```

Админ: `admin@coral.local` / `admin123`.

Страницы: `/` витрина, `/cart.html`, `/purchases.html`, `/admin.html`.
