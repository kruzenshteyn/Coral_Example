# Тесты по темам курса

В каждом файле **30 вопросов**. Один правильный ответ (A–D), если не сказано иное.

- Вопросы про **общие** темы этапа (HTML, HTTP, SQL…), а не про названия блоков учебного магазина.
- Время: 25–30 минут.
- Сдавать: номер вопроса и буква. Ключ — в конце файла, студентам не выдавать.
- Зачёт: 20/30 и выше (преподаватель может сдвинуть порог).

Печать: можно отдавать файл без секции «Ключ».

## Moodle

Копия тех же тестов в формате GIFT, **правильный ответ всегда первый**: [moodle/README.md](moodle/README.md). Импорт: Банк вопросов → Импорт → GIFT, UTF-8. Все темы сразу: [moodle/all.gift](moodle/all.gift).

Исходные `.md` не переставлять: у этапов 0–1 ключ смешанный, не всегда A.
