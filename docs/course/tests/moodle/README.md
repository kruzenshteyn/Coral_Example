# Тесты для Moodle (GIFT)

Копия вопросов из `docs/course/tests/*.md`. Исходные markdown-файлы **не менялись**: там ключ смешанный (не всегда A).

В этих `.gift` **правильный ответ всегда первый** (метка `=` в GIFT). Остальные три варианта — дистракторы (`~`).

Формат: [Moodle GIFT](https://docs.moodle.org/en/GIFT_format), кодировка **UTF-8**.

Категория при импорте: `$COURSE$/Coral/<тема>`.

## Как импортировать

1. Курс в Moodle → **Банк вопросов** → **Импорт**.
2. Формат файла: **GIFT**.
3. Кодировка: **UTF-8** (не Windows-1251).
4. Выберите один тематический `.gift` или `all.gift`.
5. Импортировать.

После импорта проверьте карточку: у вопроса с смешанным ключом в markdown (например «Макет» №1, ответ B) первым должен стоять правильный текст, а не вариант A из исходника.

## Перемешивание вариантов

- Чтобы **студенты видели правильный ответ первым**, в настройках теста/вопроса отключите «Перемешивать варианты ответа» (Shuffle).
- Если перемешивание включено, Moodle всё равно знает правильный по `=`, но порядок на экране будет случайным.

## Пересборка

Исходники правят в `docs/course/tests/*.md` (секция «Ключ» обязательна). Затем:

```bash
python docs/course/tests/_to_moodle.py
```
