# Этап 5. JavaScript

Папка: `stage-05-js/`.

- `data/products.json` — каталог товаров.
- `js/products.js` — `fetch` JSON и отрисовка карточек в `[data-catalog]` / `[data-bestsellers]`.
- `js/main.js` — модалки, валидация, выбор товара, фильтр Best sellers, бургер.

`fetch` не работает с `file://`. Запуск: из `stage-05-js` выполнить `python -m http.server 8080` и открыть http://localhost:8080/

Сценарии приёмки:

1. Карточка → модалка → Select product без входа → модалка Account.
2. Регистрация / вход → Select product → бейдж корзины, рамка `product-card_selected`, значение живёт в `localStorage`.
3. Esc и клик по оверлею закрывают диалог.
4. Невалидный email не отправляет форму.
