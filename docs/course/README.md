# Программа курса: сайт CORAL

**Начни отсюда (новичок, по шагам):** [kak-sdelat-sajt.md](kak-sdelat-sajt.md)

Цель — научить студентов собирать продающий сайт по макету Figma, а не «накликать конструктор». Один проект нарастает слоями.

## Предметная область

Макет `Coral.fig` — интернет-магазин одежды и аксессуаров. Карточка товара, корзина, вход в аккаунт — учебные сценарии для модалок и сервера.

## Этапы

1. **HTML** — семантика, формы, доступность. Папка `stage-01-html/`.
2. **CSS** — токены, сетка, адаптив. Без БЭМ.
3. **БЭМ** — рефакторинг уже готовой вёрстки.
4. **Модалки** — авторизация и карточка товара (сначала только HTML/CSS).
5. **JavaScript** — открытие модалок, выбор товара, валидация.
6. **Сервер** — один API в PHP, Django и Node.js.
7. **Адаптив и структура CSS** — блоки в отдельных папках, `@media` у каждого блока.
8. **ООП** — рефакторинг JS: классы, наследование модалок, ES-модули.
9. **База данных** — SQLite вместо JSON.
10. **Покупки и админка** — корзина, checkout, форма новой карточки.

## Правила для студентов

- Не подключать Bootstrap и React до конца курса.
- На этапах 1–5, 7 и 8 не ставить сборщики (`@import` в CSS и `type="module"` допустимы).
- Серверные варианты не должны расходиться по URL и JSON: сначала контракт, потом код.
- Модалки в макете авторизации нет — собираем по цветам и типографике Coral.

## Зачётные срезы

После каждого этапа копируем работающую папку (или коммитим `stage-N`). Преподаватель открывает HTML в браузере, без сборки.
