# Лекция 5. JavaScript в браузере

Вводная лекция к этапу 5: язык, DOM и события, fetch/async, localStorage и массивы. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена функций магазина: [../../tests/05-js.md](../../tests/05-js.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 4 темы, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: язык → DOM и события → сеть и async → данные и массивы.
3. На каждом блоке примеров назвать номер вопроса теста.
4. Показать эталон `stage-05-js/`: сначала `file://` (fetch падает), затем `python -m http.server 8080`.
5. Прогнать сценарии из [../../05-js.md](../../05-js.md): карточка → модалка → Select без входа → Account; Esc и оверлей; невалидный email.

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/05-js.md) и тест.
