# Лекция 6. HTTP, API и сервер

Вводная лекция к этапу 6: методы и идемпотентность, коды ответа, JSON-контракт, сессии и безопасность. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена функций одного стека: [../../tests/06-server.md](../../tests/06-server.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 4 темы, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: методы → коды → контракт и маршруты → сессии и безопасность.
3. На каждом блоке примеров назвать номер вопроса теста.
4. Показать [контракт](../../../../stage-06-server/api-contract.md): один JSON для PHP :8000, Django :8001, Node :8002.
5. Прогнать вход / регистрацию / Select product из [../../06-server.md](../../06-server.md).

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/06-server.md) и тест.
