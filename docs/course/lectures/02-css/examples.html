Вопросы 1, 2, 18, 19, 30

Каскад и специфичность

Конфликтующие правила перекрывают друг друга по весу селектора и порядку в файле. #id тяжелее класса. .a .b тяжелее одиночного .b. Равный вес — побеждает нижнее правило.

Равная специфичность — нижнее

.cascade-box серый (первое правило)
#winner чёрный: id сильнее

Два .cascade-box — цвет нижнего правила. Id #winner перебивает класс. !important здесь не нужен.

.a .b vs .b

внутри .a — фиолетовый (два класса)
только .b — чёрный (один класс)
.b { background: #1e2832; }
.a .b { background: #9e5cf2; }

Вопросы 3, 4, 25, 26

Блочная модель

У обеих коробок width: 200px, padding 20 и border 4. Без border-box width — только content, визуально шире.

content-box vs border-box

content-box: 200 + 40 + 8 = 248px
border-box: всё внутри 200px

Margin в width не входит ни в одной модели.

Вертикальный collapsing

margin-bottom: 24px
margin-top: 24px

Между блоками 24px, не 48. Padding и gap так не схлопываются.

min-width — порог

min 120
min 120

Ряд 280px, два flex:1, но min-width: 120px не даёт сжать карточку в ноль — вторая может вылезти.

Вопросы 8, 9, 10, 11, 24

Единицы и токены

em от шрифта элемента, rem от html. Переменные задают --accent в :root, читают var(--accent). calc(100% - 40px) — валидная ширина контейнера.

em множится, rem — от корня

16px
1.25em = 20px
ещё 1.25em = 25px (от родителя)
1.25rem = 20px от html, не от соседа

--accent в :root

background: var(--accent) — кнопка и бейдж из одного токена.

accent #9e5cf2 сменили токен — тот же класс

Не $accent (это SCSS). Контейнер лекции: width: min(1100px, calc(100% - 32px)).

Вопросы 12, 13, 14

Состояния и декор

:hover — наведение. :focus-visible — кольцо в основном с клавиатуры. ::after — виртуальный ребёнок, стрелка «Shop now» без лишнего HTML.

Наведите и нажмите Tab

Shop now

Hover красит фон в primary. Tab показывает outline. У кнопки справа стрелка из ::after { content: " →" }.

Почему не outline: none

a:focus-visible,
button:focus-visible {
  outline: 2px solid #9e5cf2;
  outline-offset: 3px;
}

Кликом мыши кольца может не быть. С клавиатуры — должно. :focus-visible не заменяет tabindex.

Вопросы 17, 20, 23, 28, 29

Картинки, медиа, шрифт, видимость

object-fit: cover заполняет бокс и может обрезать края. Медиазапрос 768 — про viewport. Opacity 0 ≠ display none. Шрифт — @font-face (здесь через Google Fonts).

cover vs contain

Слева cover (как фото карточки Coral), справа contain (как логотипы брендов).

Сейчас viewport ≤ 768px — сработал @media.

opacity: 0 не display: none

место занято:

opacity 0

Бокс есть, события возможны.

места нет:

none

Соседа сдвинуло. Как hidden.
