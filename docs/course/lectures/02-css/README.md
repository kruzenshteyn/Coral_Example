# Лекция 2. CSS: каскад, коробка, раскладка

Вводная лекция к этапу 2: каскад и специфичность, блочная модель, Flex и Grid, позиция, токены, состояния и медиа. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена классов магазина: [../../tests/02-css.md](../../tests/02-css.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 7 тем, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: каскад → коробка → flex/grid → позиция → единицы → состояния → медиа.
3. На каждом блоке примеров назвать номер вопроса теста.
4. Открыть эталон `stage-02-css/index.html` — шапка flex, каталог grid на 4 колонки, токены в `:root`.
5. Прогнать ДЗ из [../../02-css.md](../../02-css.md).

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/02-css.md) и тест.
