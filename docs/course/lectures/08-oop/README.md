# Лекция 8. ООП в JavaScript

Вводная лекция к этапу 8: класс и объект, наследование vs композиция, `this`, модули и принципы. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена файлов магазина: [../../tests/08-oop.md](../../tests/08-oop.md).

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: класс → отношения → композиция → this/модули → принципы.
3. На каждом блоке примеров назвать номер вопроса теста.
4. На эталоне `stage-08-oop/` показать дерево `js/` и `App` как фасад; поднять `python -m http.server`.
5. Сравнить с этапом 5: был IIFE и `PRODUCTS`, стало классы. Поведение страницы то же.

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/08-oop.md) и тест.
