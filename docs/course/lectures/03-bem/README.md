# Лекция 3. БЭМ: независимые блоки

Вводная лекция к этапу 3: имена блока, элемента и модификатора, независимость от родителя, микс и структура файлов. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про дословные классы магазина: [../../tests/03-bem.md](../../tests/03-bem.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 4 темы, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: имена → независимость → структура → практика.
3. На каждом блоке примеров назвать номер вопроса теста.
4. На эталоне `stage-03-bem/index.html` разобрать вслух: блок / элемент / модификатор у шапки и карточки.
5. Вырезать одну карточку и вставить в футер — вид не должен развалиться. Затем ДЗ из [../../03-bem.md](../../03-bem.md).

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/03-bem.md) и тест.
