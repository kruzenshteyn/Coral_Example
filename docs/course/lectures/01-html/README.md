# Лекция 1. HTML как смысл страницы

Вводная лекция к этапу 1: документ без CSS, семантика, ссылка vs кнопка, формы и валидность. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена классов магазина: [../../tests/01-html.md](../../tests/01-html.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 6 тем, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: каркас → семантика → ссылки → заголовки → формы → валидность.
3. На каждом блоке примеров назвать номер вопроса теста.
4. Отключить CSS в DevTools на эталоне `stage-01-html/index.html` — страница всё ещё читается.
5. Прогнать [валидатор](https://validator.w3.org/), затем ДЗ из [../../01-html.md](../../01-html.md).

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/01-html.md) и тест.
