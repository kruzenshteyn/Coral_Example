# Лекция 10. Корзина, заказ, права, админка

Вводная лекция к этапу 10: аутентификация vs авторизация, корзина и снимок заказа, CRUD админки, XSS/CSRF. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена CSS: [../../tests/10-shop-admin.md](../../tests/10-shop-admin.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 4 темы, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: кто вы → корзина/заказ → админка CRUD → безопасность ввода.
3. На каждом блоке примеров назвать номер вопроса теста.
4. На эталоне `stage-10-shop-admin/`: войти как покупатель, Checkout, затем `admin@coral.local` и новая карточка.
5. Показать 401 без cookie, 403 на админ-API обычным пользователем, 400 на пустой корзине.

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/10-shop-admin.md) и тест.
