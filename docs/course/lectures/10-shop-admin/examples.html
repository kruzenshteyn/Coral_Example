403

POST /api/admin/products → вошёл, но не админ.

Админ

Тот же login, роль другая. Least privilege: админ-API только ему.

Вопросы 14, 17, 20, 21, 27

XSS, CSRF, валидация на сервере

Название без экранирования — скрипт на витрине. Демо показывает строку как текст, не выполняет её. CSRF — POST с cookie. Цену проверяет сервер.

Сырой вывод vs textContent

Как выглядело бы в innerHTML — только как текст, скрипт не запускаем.

Как надо: textContent / экранирование.

CSRF и серверная цена

POST /api/checkout     cookie сессии → опасен CSRF
GET  /api/products     без побочек → не цель CSRF
price: -1 в DevTools   клиент обойти легко
сервер: price > 0      обязательно

description → textContent
не innerHTML, не eval

Stock в учебной модели часто упрощают. CSRF-токен и SameSite — защита POST checkout.
