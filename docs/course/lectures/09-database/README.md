# Лекция 9. Базы данных и SQL

Вводная лекция к этапу 9: таблицы и ключи, CRUD, транзакции SQLite, нормализация и SQL-инъекция. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена файлов PHP/Django: [../../tests/09-database.md](../../tests/09-database.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 4 темы, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: модель → CRUD → транзакции/SQLite → проектирование и безопасность.
3. На каждом блоке примеров назвать номер вопроса теста.
4. Открыть `stage-09-database/data/schema.sql` и показать три таблицы, UNIQUE email, FK.
5. Поднять один стек, `GET /api/products` — данные уже из `coral.db`, не из JSON в рантайме.

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/09-database.md) и тест.
