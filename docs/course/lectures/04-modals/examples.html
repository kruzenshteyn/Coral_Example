Вопросы 3, 4, 5, 6, 11, 17, 22, 26, 29

Доступность

role="dialog" и aria-modal="true". aria-labelledby — id заголовка. Фокус внутрь, Tab циклится. Крестик — кнопка с именем, не голая иконка.

ARIA в разметке Account

<div
  class="modal"
  id="modal-auth"
  role="dialog"
  aria-modal="true"
  aria-labelledby="auth-title"
>
  <h2 id="auth-title" tabindex="-1">Account</h2>
  <button type="button" aria-label="Close">×</button>
</div>

aria-modal — контент вне воспринимается как неактивный. tabindex="-1" на заголовке: программный фокус есть, в Tab-цикл не входит. Где есть — inert на фоне.

Имя у крестика

aria-label="Close" — скринридер поймёт
только ::after, без имени — нельзя

Не голая иконка без имени. Ловушку фокуса (Tab циклится внутри) и Escape подключат скриптом на этапе 5.

Вопросы 7, 9, 16, 19, 23, 25, 27, 28

UX закрытия

Escape закрывает. На body — overflow: hidden. Фокус возвращают на открывший элемент. Клик оверлея — обычный UX, не для критичных форм. Анимация 200ms, не 5 секунд без закрытия.

Клик оверлея не всегда

Закрыть кликом по затемнению — обычный UX для Account. Для «удалить безвозвратно» оставляют только кнопки в панели: случайный клик мимо не должен закрыть.

Escape, возврат фокуса и ловушку Tab подключат на этапе 5. Сейчас закрытие — ссылка на #.

Вопросы 12, 13, 15, 18, 20, 21, 24, 30

:target, формы, несколько окон

Hash открывает диалог без JS — progressive enhancement. Минус: слабый фокус и история. Форма входа внутри — нормальный паттерн. Крестик в форме — type="button", иначе submit.

:target без JS

Открыть #target-auth · Закрыть (#)

Account по hash

Сработал :target. Фокус остался на ссылке — в этом слабость. История браузера получила hash.

Закрыть

В Coral: Account → href="#modal-auth", закрытие → href="#". Класс для скрипта появится на этапе 5.

type="button" в форме

Крестик и Close — type="button", иначе форма уйдёт. Форма в диалоге валидна. Диалог лучше оставить в HTML со hidden / не :target, чем рисовать картинкой.
