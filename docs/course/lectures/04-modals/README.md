# Лекция 4. Модальные окна и диалоги

Вводная лекция к этапу 4: оверлей и слой, доступность диалога, закрытие, `:target` и несколько окон. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про дословную разметку магазина: [../../tests/04-modals.md](../../tests/04-modals.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 4 темы, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: суть → доступность → UX закрытия → `:target` и формы.
3. На каждом блоке примеров назвать номер вопроса теста.
4. Открыть Account без JS (`:target`) и с JS (класс `modal_open`): Tab, Escape, клик по оверлею.
5. Сверить эталон `stage-04-modals/index.html`, затем ДЗ из [../../04-modals.md](../../04-modals.md).

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/04-modals.md) и тест.
