# Лекция 0. Макет как ТЗ

Вводная лекция к этапу 0: как читать макет (сетка, токены, типографика, состояния UI) и переносить это в вёрстку. Вопросы теста разобраны **по смыслу**, с примерами из Coral и CSS.

Тест общий, не про конкретный файл Figma: [../../tests/00-figma.md](../../tests/00-figma.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 9 тем, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам лекции (сетка → отступы → токены → тип → состояния → ассеты).
3. На каждом блоке примеров назвать номер вопроса теста.
4. Снять 5–8 токенов Coral, затем ДЗ из [../../00-figma.md](../../00-figma.md).

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/00-figma.md) и тест.
