# Лекция 7. Адаптивная вёрстка

Вводная лекция к этапу 7: viewport и стратегия, резина, картинки и единицы, UX и медиа в файле блока. Вопросы теста разобраны **по смыслу**, с примерами из Coral.

Тест общий, не про имена классов магазина: [../../tests/07-adaptive.md](../../tests/07-adaptive.md).

## Файлы

| Файл | Зачем |
| --- | --- |
| [lecture.md](lecture.md) | Текст лекции: 4 темы, все 30 вопросов |
| [examples.html](examples.html) | Живые примеры (открыть в браузере, можно на проекторе) |

Ключ с буквами A–D остаётся в файле теста и студентам не выдаётся. Лекция объясняет правильную идею, не «зазубрить B».

## Как провести

1. Открыть [examples.html](examples.html) рядом с текстом.
2. Идти по разделам: viewport → резина → картинки → UX и сопровождение.
3. На каждом блоке примеров назвать номер вопроса теста.
4. Сжать окно / DevTools 1280 → 1024 → 768 → 375 на эталоне `stage-07-adaptive/index.html`: сетка 4→3→2→1, бургер на 768.
5. Показать, что `@media` живут в `css/blocks/*/`, не свалкой в конце. Затем ДЗ из [../../07-adaptive.md](../../07-adaptive.md).

Время: одна пара (45–90 минут). Дальше — [инструкция этапа](../../guides/07-adaptive.md) и тест.
