# Инструкция. Этап 0 — макет как ТЗ

## Зачем этап

Верстка «по картинке» без токенов даёт плавающие отступы и случайные цвета. Макет читают как спецификацию: что за блок, какие состояния, какие числа.

## Что открыть

- `Coral.fig`
- `design/tokens.md` (после разбора)
- [Карта блоков](../00-figma.md)

## Теория

- [Что такое HTML](https://developer.mozilla.org/ru/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content) — страница как документ, не как холст.
- [Визуальное форматирование](https://developer.mozilla.org/ru/docs/Learn_web_development/Core/Styling_basics) — отступы, шрифт, цвет станут CSS.
- [Доступность: что это](https://developer.mozilla.org/ru/docs/Learn_web_development/Core/Accessibility) — hover в макете не заменяет фокус клавиатуры.
- [Цвет в CSS](https://developer.mozilla.org/ru/docs/Web/CSS/color_value) — HEX из макета попадает в переменные.
- Figma Help: [Components](https://help.figma.com/hc/en-us/articles/360038662654), [Auto layout](https://help.figma.com/hc/en-us/articles/5739229107479).

## Почему так

| Решение | Почему | Альтернатива, которую не берём |
| --- | --- | --- |
| Сначала карта блоков, потом теги | Иначе студенты рисуют `div` на всё | Сразу копировать пиксели в CSS |
| Токены в таблицу | Один primary на кнопки и бейджи | «Приблизительно фиолетовый» на глаз |
| Состояния (hover, sale) выписать | Их нет на статичном PNG | Верстать только default |
| Опечатки макета на этапе вёрстки копируем | Учимся следовать ТЗ | Сразу «улучшать» копирайт |

## Пошагово

1. Откройте файл макета. Найдите фрейм главной (обычно самый высокий, ~1920 по ширине).
2. Выпишите блоки сверху вниз: шапка, герой, категории, карточки, баннер, подвал, попапы.
3. Для каждого блока ответьте: зачем он пользователю? Какой HTML-тег ближе — `header`, `nav`, `article`, `form`?
4. Снимите 5–8 цветов и 2–3 семейства шрифтов. Запишите HEX и px заголовков.
5. Найдите повторяющийся компонент (карточка, кнопка). Это будущий блок БЭМ, не десять копий уникальных классов.
6. Проверьте, есть ли mobile-фрейм. Если нет — на этапе 7 брейкпоинты всё равно зададите в коде (это нормально).
7. Сохраните заметки: `notes-figma.md` или таблица в тетради.

## Пример записи

```text
Блок: карточка товара
Зачем: выбрать позицию из каталога
Тег: article
Состояния: обычная, hover, Sale, Hot
Токены: цена 16px/600, бейдж primary
```
