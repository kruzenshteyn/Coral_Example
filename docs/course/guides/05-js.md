## Почему так

| Решение | Почему | Не берём |
| --- | --- | --- |
| Карточки из `products.json` | Один источник данных, HTML не дублирует 8 статей | Копипаста `article` в разметке |
| `createElement` + `textContent` | Нет XSS из названия товара | `innerHTML` со строкой из JSON |
| Класс `modal_open`, не `style.display` | Стили остаются в CSS | JS-стилист |
| Клиентская валидация **до** сервера | Мгновенная обратная связь | Только `alert` |
| `localStorage` для выбора товара | Учебный persistence без бэкенда | Притворяться, что данные на сервере |
| Локальный HTTP-сервер | `fetch` к JSON с `file://` блокируется | «Просто открой html» |

`localStorage` виден любому JS на origin — это не сессия сервера. На этапе 6 замените смыслом cookie + API.

## Пошагово

1. Из папки этапа:

```powershell
python -m http.server 8080
```

Откройте http://localhost:8080/ — не файл с диска.

2. Файл `data/products.json` — массив объектов: `id`, `title`, `price`, `image`, …

3. Загрузка:

```javascript
async function loadProducts() {
  const response = await fetch("data/products.json");
  if (!response.ok) throw new Error("HTTP " + response.status);
  return response.json();
}
```

`fetch` **не** бросает исключение на 404 — проверяйте `response.ok` ([MDN](https://developer.mozilla.org/ru/docs/Web/API/Fetch_API/Using_Fetch#proverka_uspeshnosti_zaprosa)).

4. Рисуйте карточки в `[data-catalog]` и бестселлеры фильтром `bestseller`.
5. Модалка: `element.classList.add('modal_open')`. Esc и клик по `.modal__overlay` снимают класс.
6. На `submit` формы: `event.preventDefault()`, проверка email и длины пароля, показ `.form__error`.
7. После «входа» пишите пользователя в `localStorage`. Select product без пользователя открывает Account.

## Пример: делегирование

Один слушатель на `document` ловит клик по любой будущей карточке из JSON. Не вешайте listener в цикле на каждую карточку до того, как они появятся в DOM.

```javascript
document.addEventListener("click", (event) => {
  const media = event.target.closest(".product-card__media");
  if (!media) return;
  // открыть модалку
});
```
