## 1. Цели и задачи освоения дисциплины

### 1.1. Цель

Сформировать способность **проектировать и реализовывать веб-приложение цифрового бизнеса по техническому заданию (макету)**: клиентский интерфейс, серверный API, хранение данных, сценарии покупки и администрирования.

Учебный полигон — интернет-магазин **CORAL** (одежда и аксессуары). Сайт собирается не в конструкторе, а слоями: макет → HTML → CSS → БЭМ → модалки → JavaScript → HTTP-API → адаптив → ООП → SQLite → корзина и админка.

### 1.2. Задачи

1. Снять с макета Figma требования к интерфейсу цифрового сервиса (сетка, токены, состояния).
2. Реализовать семантическую вёрстку и клиентские стили по ТЗ.
3. Организовать независимые UI-блоки (БЭМ) и диалоги.
4. Подключить клиентскую логику и обмен с сервером.
5. Выбрать стек реализации API (PHP / Django / Node.js) при едином контракте.
6. Обеспечить адаптив, модульную структуру кода и хранение в СУБД.
7. Реализовать контуры учёта: корзина, заказ, роли, админка карточек.

### 1.3. Место в ОПОП

Дисциплина относится к части, формируемой участниками образовательных отношений. Опирается на информатику, основы программирования и дискретную математику (при наличии в УП). Является основой для практик, курсовых и ВКР по веб-системам цифрового бизнеса.

## 5. Содержание дисциплины

Работа выполняется в **своей** папке (`site/`). `stage-N` — эталон. Цикл темы: лекция → `guides/` → практика → «Проверка» → тест 30 вопросов.

### Тема 0. Макет как ТЗ

Макет — спецификация цифрового сервиса. Сетка, max-width, шаг 8px, токены, компоненты, hover/disabled, pixel-perfect. Практика: карта блоков Coral, HEX, шрифты. Тест `tests/00-figma.md`.

### Тема 1. HTML

Каркас документа, семантика, ссылка vs кнопка, `alt`, `label`, формы. Вход — `login.html`, товар — `product.html`. Эталон `stage-01-html/`. Тест `tests/01-html.md`.

### Тема 2. CSS

Каскад, `border-box`, Flex/Grid, `:root`, `:focus-visible`. Токены Coral, контейнер 1320px. Без БЭМ и без адаптива (этап 7). Эталон `stage-02-css/`. Тест `tests/02-css.md`.

### Тема 3. БЭМ

Блок, элемент, модификатор, независимость. Рефакторинг этапа 2. Эталон `stage-03-bem/`. Тест `tests/03-bem.md`.

### Тема 4. Модальные окна

Оверлей, `role="dialog"`, `:target`. `#modal-auth`, `#modal-product`. Эталон `stage-04-modals/`. Тест `tests/04-modals.md`.

### Тема 5. JavaScript

DOM, `fetch`, `localStorage`, валидация. Каталог из JSON, локальный HTTP-сервер. Эталон `stage-05-js/`. Тест `tests/05-js.md`.

### Тема 6. HTTP, API и сервер

Методы и коды, JSON, сессия, единый контракт PHP / Django / Node. Эталон `stage-06-server/`. Тест `tests/06-server.md`.

### Тема 7. Адаптив

Desktop-first Coral, брейкпоинты 1100 / 768 / 480, бургер, CSS по папкам блоков. Эталон `stage-07-adaptive/`. Тест `tests/07-adaptive.md`.

### Тема 8. ООП

Классы, `Modal` → `AuthModal`, фасад `App`, ES-модули. Эталон `stage-08-oop/`. Тест `tests/08-oop.md`.

### Тема 9. База данных

SQLite, PK/FK, SQL, инъекция. Контракт HTTP не меняется. Эталон `stage-09-database/`. Тест `tests/09-database.md`.

### Тема 10. Корзина, заказ, админка

Authn/authz, снимок цены, checkout, XSS. Эталон `stage-10-shop-admin/`. Тест `tests/10-shop-admin.md`.

### Тема 11. Зачёт

Разбор ошибок, защита проекта по ФОС.

## 8. Условия реализации

Компьютерный класс, браузер, редактор кода, Python 3 (`http.server`), по выбору группы PHP **или** Node.js **или** Django. Макет `Coral.fig`. Без Bootstrap и React.

Литература: материалы курса `docs/course/`; MDN; документация стека; SQLite.
