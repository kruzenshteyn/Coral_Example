# Этап 7. Адаптив и файловая структура БЭМ

Общие правила адаптива — во [вводной лекции](lectures/07-adaptive/lecture.md), живые примеры: [lectures/07-adaptive/examples.html](lectures/07-adaptive/examples.html).

Папка: `stage-07-adaptive/`.

Цель занятия — не «ещё три @media в одном файле», а две вещи сразу:

1. каждый БЭМ-блок живёт в своей папке;
2. адаптив пишется **внутри блока**, а не свалкой в конце `style.css`.

## Структура CSS

```
css/
  index.css                 ← только @import
  common/
    variables.css
    reset.css
    typography.css
    container.css
  blocks/
    header/header.css
    logo/logo.css
    hero/hero.css
    product-card/product-card.css
    modal/modal.css
    ...
```

HTML подключает один файл: `css/index.css`. Сборщик на этом этапе не ставим: браузер сам тянет импорты. В проде файлы склеивают — это тема «что дальше».

## Брейкпоинты

Макет Figma — desktop. Идём desktop-first.

| Ширина | Сетка | Что меняется |
| --- | --- | --- |
| > 1100 | 4 колонки товаров | как в макете |
| ≤ 1100 | 3 колонки | герой 2 фото + текст снизу, подвал 2×2 |
| ≤ 768 | 2 колонки | бургер, скрытый поиск текстом, баннер столбиком, меню колонкой |
| ≤ 480 | 1 колонка | логотип короче, категории стопкой, модалка на всю ширину |

Проверка: DevTools → 1280, 1024, 768, 375. Клик по бургеру, открытие карточки, форма входа.

## ДЗ

Вынести любой новый блок (например, `cart`) в `css/blocks/cart/cart.css` с собственными `@media` на 768 и 480.
