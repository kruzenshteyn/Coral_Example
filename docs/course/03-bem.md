# Этап 3. БЭМ

Общие правила БЭМ — во [вводной лекции](lectures/03-bem/lecture.md), живые примеры: [lectures/03-bem/examples.html](lectures/03-bem/examples.html).

Папка: `stage-03-bem/`.

Тот же визуал, что на этапе 2. Классы переименованы:

- `header-top` → `header__top`
- `product-card-media` → `product-card__media`
- `badge-sale` → `product-card__badge_type_sale`
- `product-card-selected` → `product-card_selected`

Карточка `.product-card` не зависит от секции: её можно вставить в модалку.
