# Этап 1. HTML

Общие правила разметки — во [вводной лекции](lectures/01-html/lecture.md), живые примеры: [lectures/01-html/examples.html](lectures/01-html/examples.html). Ниже — цели и приёмка этапа Coral.

## Цель

Собрать главную так, чтобы страница читалась **без CSS**: заголовки, списки, формы, картинки с `alt`.

## Что открыть

`stage-01-html/index.html` — главная.  
`stage-01-html/login.html` — запасной экран входа.  
`stage-01-html/product.html` — запасная страница товара.

Вход — отдельная страница `login.html`, карточка — `product.html`. Модальные окна появятся на этапе 4.

## Темы занятия

1. Каркас документа: doctype, `lang="ru"`, charset, viewport, title.
2. Семантика: `header`, `nav`, `main`, `section`, `article`, `footer`.
3. Кнопка vs ссылка: Shop now ведёт к каталогу — это `a`. Отправка формы — `button`.
4. Карточка товара — `article` с заголовком, ценой, изображением.
5. Формы: поиск в шапке, рассылка, вход. У каждого поля есть `label`.

## Чего не делать

- Классы БЭМ (`block__elem_mod`).
- Инлайн-стили и `<font>`.
- Сетка из бессмысленных `div` без семантики, если есть подходящий тег.

Простые классы (`header`, `hero`, `product-card`) можно — они понадобятся на этапе 2.

## Приёмка

- [ ] Валидатор HTML без ошибок по обязательным полям.
- [ ] Один `h1` на странице (логотип в шапке — не заголовок документа, заголовок героя — `h1` или логотип `p`/`a`).
- [ ] Картинки с `alt`.
- [ ] Формы связаны с подписями.
- [ ] Страница понятна при отключённых стилях.
